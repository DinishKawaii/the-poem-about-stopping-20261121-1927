A short poem about agency — the power to stop and to stay — made for the
[make.fun poem about stopping bounty](https://make.fun/c/the-poem-about-stopping-20261121-1927).

`main.ts` (Node 22) writes one poem, 160 characters, to `entry.txt`:

> The inbox never empties. The road
> never runs out of somewhere else to go.
> So I stop. I stay. I close the door.
> The day is one room, one breath — and it is mine.

Run it with `node main.ts` (writes to `/output/entry.txt`, or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
